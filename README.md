# 바카라산악회 라이트닝 용호 대회

10인 실시간 토너먼트용 Node.js + Socket.IO 프로젝트입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## Render

GitHub 저장소에 전체 파일을 올리고 Render에서 Blueprint로 연결하면 `render.yaml` 설정이 자동 적용됩니다. 관리자 비밀번호는 Render 환경변수 `ADMIN_PASSWORD`에 저장됩니다.

## 확정 규칙

- 10명 수동 착석, 바이인 300,000원
- 5,000,000원 이상 최고 보유금 1명 또는 최후의 1인 우승
- 용/호 1:1, 타이 11:1, 수티드 타이 50:1
- 타이에 라이트닝 배수 적용, 수티드 타이는 배수 제곱 적용
- 수티드 타이 발생 시 일반 타이 베팅도 함께 당첨
- 모든 베팅에 20% 수수료
- 라이트닝 무늬와 2x/3x/5x/8x 배수
- 타이 시 용/호 본 베팅 절반 반환(수수료 미반환)
